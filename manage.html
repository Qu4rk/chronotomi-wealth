Settings

To publish changes directly to the website, a GitHub access token is required. This only needs to be set up once.

  1. Go to github.com → Settings → Developer settings → Personal access tokens
  2. Create a Fine-grained token for the chronotomi-wealth repository
  3. Grant Contents: Read and write permission
  4. Paste the token below
